## Cara update manual dari HP

1. Buka repository GitHub.
2. Masuk ke branch `main`.
3. Buka file yang akan diganti.
4. Tekan ikon pensil/Edit atau pilih Upload files sesuai tampilan GitHub.
5. Ganti file dengan file dari folder UPDATE-V2.6.
6. Commit changes.
7. Ulangi untuk 4 file di atas.
