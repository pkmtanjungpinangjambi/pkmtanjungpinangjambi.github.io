# Standar Media Sosial — Icon Only

Tujuan: menjaga website tetap menjadi pusat informasi dan mencegah blok media sosial menjadi jalur keluar visual utama.

## Aturan
- Media sosial tetap dapat diakses.
- Tampilan hanya ikon resmi.
- Tidak ada feed, embed, thumbnail, kartu promosi, atau tombol ajakan mengikuti.
- Ikon harus mempunyai `aria-label` dan `title`.
